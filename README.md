# 随记 · 文本笔记

一个跑在 GitHub Pages 上的极简云笔记。打开网页就能写，数据先存本机浏览器，再通过你自己的**私密 Gist** 在多台设备间同步。

> 纯静态站点，无后端、无数据库、无第三方统计，代码公开但笔记不公开。

## 功能

- **三栏布局**：笔记本 / 笔记列表 / 编辑器，手机端自动切换为「列表 → 详情」的翻页式交互
- **Markdown 实时预览**：标题、列表、待办清单、代码块、引用、表格、链接，自带轻量渲染器（无任何第三方库）
- **自动保存**：编辑即存，无需保存按钮
- **笔记本 + `#标签`**：标签从正文里自动提取，侧栏可点选筛选
- **搜索、排序、置顶、回收站**（软删除可恢复，彻底删除后不可恢复）
- **跨设备同步**：GitHub Gist 私有仓库，打开页面自动拉取、编辑后自动推送，按笔记 ID + 更新时间合并
- **导出 / 导入**：全部笔记导出为 JSON（可再导入）或单个 `.md`
- **可安装 PWA**：手机浏览器「添加到主屏幕」后像 App 一样全屏使用，断网也能打开（Service Worker 缓存）
- **浅色 / 深色 / 跟随系统**主题
- **快捷键**：`Ctrl+N` 新建 · `Ctrl+K` 搜索 · `Ctrl+S` 保存并同步 · `Esc` 返回

## 启用跨设备同步（一次性配置）

GitHub Pages 只能托管静态文件，没法存数据，所以同步借用 GitHub 自己的 Gist 服务（免费、私有）：

1. 打开 [Token 生成页](https://github.com/settings/tokens/new?scopes=gist&description=suiji-notes)
2. 勾选 **gist** 权限，生成并复制 Token（形如 `ghp_xxx`）
3. 回到网页，点左下角「未开启同步」，粘贴 Token，点「立即同步」

第一次同步会自动创建一个名为「随记 · 文本笔记同步数据」的**私密 Gist**，并把 Gist ID 记住。之后在其他设备（手机、另一台电脑）上打开同一个网址，重复第 3 步即可，数据会自动合并。

- Token 只保存在本机 `localStorage`，不会写进代码或提交到仓库
- 想换设备或重置：清掉页面本地数据后重新配置即可
- 同一条笔记冲突时以 `updatedAt` 较新的一方为准；删除通过墓碑记录同步，不会"复活"

## 本地运行

```bash
python -m http.server 8777
# 打开 http://127.0.0.1:8777/
```

`file://` 直接双击打开也能用（此时 Service Worker 不生效）。

## 文件结构

```
index.html            页面结构与图标
styles.css            全部样式（含深色主题与响应式）
app.js                状态管理、Markdown 渲染、Gist 同步
manifest.webmanifest  PWA 清单
sw.js                 Service Worker（离线缓存）
icon.svg              图标
```

## 数据存放

| 位置 | 内容 |
| --- | --- |
| 浏览器 `localStorage` | `suiji.data.v1` 笔记数据；`suiji.sync.v1` 同步配置；`suiji.ui.v1` 界面状态 |
| 私有 Gist `suiji-notes.json` | 笔记数据副本，用于多设备同步 |

**建议**：重要内容定期用「导出 → 全部为 JSON」备份一份，本地存储清空（换浏览器、清缓存）时数据不会丢。
