    同步设置

    笔记会存放在你 GitHub 账号下的一个私密 Gist（只有你自己能看）。GitHub Pages 是纯静态托管，所以需要这个 Gist 来做跨设备同步。

    1. 打开 GitHub Token 生成页
    2. 勾选 gist 权限，期限随意，生成后复制
    3. 粘贴到下面，点"立即同步"（Gist ID 留空会自动创建）

    Token 只保存在本机浏览器里，不会写进代码或仓库。
